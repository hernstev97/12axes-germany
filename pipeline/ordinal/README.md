# Ordinaler Momentadapter

Vor Empirie ungeprüfte produktive Autorenfassung. Herkunft und synthetische Gegenrechnungen: `reports/loop/authors/ESS-ADAPTER-resume-proposal.md`. Code bytegleich übernommen aus dem dort gehashten eigenen Artefakt. Keine Datei-Eingabe oder Exportautomatik, keine ESS-Fälle im Code. Erst nach Plan-/Kategorien-/Designfestschreibung und den Übergangsreviews verwenden.

`oa_build(items, manifest, weight, psu, stratum, domain)` bildet exakt neun geordnete Items, vollständige gemeinsame Domäne und die volle gemeinsame gewichtete Moment-/Designkovarianz. Nichtantworten vorher nach Quellenvertrag in NA überführen. Alle Design-PSUs einschließlich Null-Domänenbeiträgen erhalten; kein automatisches Renesting, keine Singleton-/Kategorie-Reparatur. R4.5.3, lavaan0.7.2 und pbivnorm0.6.0 fest gebunden.

`oa_fit` importiert ausschließlich Summary-Momente/Gamma/DWLS; `oa_public` gibt nur feste Aggregate aus. Das private In-Memory-Objekt enthält Fallbeiträge und ist kein öffentlicher Export. Landlock-/Laufzeitwrapper und tatsächliche ESS-Importgates werden als eigener Codevertrag vorbereitet. Synthese, Validitäts-/Abdeckungsprüfung und empirische Ergebnisse bleiben getrennt.
