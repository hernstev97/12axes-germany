# Berichte

`phasen/` enthält den belegbaren Stand der Recherche und späteren Phasen. Review-Findings samt Nachprüfung werden künftig unter `reviews/` abgelegt; das Format steht in [docs/reviews/README.md](../docs/reviews/README.md).

Ein Recherchebericht ist kein empirischer Ergebnisbericht. Noch keine wissenschaftlichen Abnahmen durchgeführt. Technische, methodische und Verständnisprüfungen bleiben getrennt. Fehlende Prüfungen werden als offen geführt.
